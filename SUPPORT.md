# Support

Thanks for using HEAVEN-GeoIntel. Here is where to go for help.

## Questions and discussion

- **General questions, ideas, how-to:** open a thread in
  [GitHub Discussions](https://github.com/nishu2402/HEAVEN-GeoIntel/discussions).
- **Documentation:** the [README](./README.md) covers setup, every lookup mode,
  the REST API and runtime configuration. The
  [OSINT roadmap](./docs/OSINT-ROADMAP.md) tracks what is planned.

## Bugs and feature requests

- **Found a bug?** open a
  [bug report](https://github.com/nishu2402/HEAVEN-GeoIntel/issues/new?template=bug_report.md).
- **Want a new source, pivot or feature?** open a
  [feature request](https://github.com/nishu2402/HEAVEN-GeoIntel/issues/new?template=feature_request.md).

Please search existing issues first, and never paste real phone numbers, emails
or other personal data into a public issue. Use the Twilio test numbers
`+14155552671` / `+14155552672` in examples.

## Security issues

Do not open a public issue for a vulnerability. Report it privately through a
[GitHub Security Advisory](https://github.com/nishu2402/HEAVEN-GeoIntel/security/advisories/new),
following the process in [SECURITY.md](./SECURITY.md).

## What to expect

This project is maintained by one person on their own time, so please be patient.
There is no service-level agreement for general support. Security reports follow
the timeline in SECURITY.md: an acknowledgement within 72 hours.
