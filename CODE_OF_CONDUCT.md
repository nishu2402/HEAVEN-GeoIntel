# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

Maintainers are responsible for clarifying and enforcing the standards of
acceptable behavior. They will take appropriate and fair corrective action in
response to any behavior they deem inappropriate, threatening, offensive, or
harmful.

## Reporting

If you witness or experience behavior that violates this code of conduct,
report it via a private message to a maintainer on the [GitHub project page](https://github.com/nishu2402/HEAVEN-GeoIntel),
or by opening a [GitHub Security Advisory](https://github.com/nishu2402/HEAVEN-GeoIntel/security/advisories/new)
(which lets you contact the maintainers confidentially).

All complaints will be reviewed and investigated promptly and fairly.
Maintainers are obligated to respect the privacy and security of the reporter.

## Enforcement

Project maintainers may use any of the [enforcement actions described in the
Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines),
up to and including a permanent ban from the project.
